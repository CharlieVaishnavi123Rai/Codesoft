# CodSoft Internship - Python Programming Tasks

This repository contains all the tasks I completed during my CodSoft Python Internship.

---

## 🚀 Task 1: To-Do List Manager
**Description:**  
A command-line To-Do List application built using Python.  
**Features:**
- Add new tasks
- View all pending tasks
- Mark tasks as completed
- Delete tasks
- Data saved in a file so it doesn't get lost

**Technologies Used:** Python, File Handling

---

## 🔐 Task 2: Password Generator
**Description:**  
A secure password generator that creates strong random passwords based on user requirements.  
**Features:**
- User can set password length
- Option to include uppercase, lowercase, numbers, and special characters
- Generates strong and random passwords instantly

**Technologies Used:** Python, random module, string module

---

## 🎮 Task 3: Rock Paper Scissors Game
**Description:**  
A fun command-line Rock Paper Scissors game where user plays against the computer.  
**Features:**
- User vs Computer gameplay
- Score tracking for both player and computer
- Option to play multiple rounds
- Input validation

**Technologies Used:** Python, random module
